# After Effects 準拠のカメラ・コンポジション設定：設計方針

- 作成日：2026-11-11
- 状態：方針決定。土台（モデル・プレビュー枠・書き出し）と §6 のプロパティ画面は実装済み（§8）。

## 1. 目的

カメラと配置の設定を、After Effects（以下AE）の考え方と数値にそろえる。
AEで作るカメラと同じ設定をこのアプリで再現でき、このアプリの数値をそのままAEに持ち込めるようにする。

要件は次の4つ。

1. AEの「カメラ設定」と同じ項目で画角を決められる。
2. mm と px の換算をAEと同じにする。
3. コンポジションサイズを設定でき、それに対する画像のスケールを決められる。
4. 設定項目を「基本」と「応用」に分け、基本だけで最低限の調整（特にカメラからの距離）ができる。

## 2. AEの決まりごと（前提）

| 項目 | AEの定義 |
|---|---|
| mm ⇔ px | 72 dpi で換算する。1 px = 25.4 / 72 mm（約0.3528 mm） |
| フィルムサイズ測定 | フィルムサイズが対応するコンポの辺。水平＝幅、垂直＝高さ、対角＝対角線 |
| ズーム | `ズーム = 測定辺の長さ × 焦点距離 ÷ フィルムサイズ` |
| 画角 | `画角 = 2 × atan(フィルムサイズ ÷ (2 × 焦点距離))`（測定辺方向の角度） |
| z = 0 の平面 | スケール100%のコンポサイズの平面が、カメラにちょうど収まる位置 |
| カメラの初期位置 | `(コンポ幅/2, コンポ高さ/2, −ズーム)`。目標点は `(コンポ幅/2, コンポ高さ/2, 0)` |
| 座標軸 | +X 右、+Y 下、+Z 奥。単位は px |

確認用の数値（AEのカメラ設定ダイアログ。コンポ 1920×1080、フィルム 36 mm、焦点距離 24 mm、水平）：

- ズーム ＝ 1920 × 24 ÷ 36 ＝ 1280 px ＝ 451.56 mm
- コンポジションサイズ ＝ 1920 px ＝ 677.33 mm
- 画角 ＝ 73.74°

この数値はテスト（`test_composition_matches_after_effects_camera_dialog`）で固定してある。

## 3. データモデル

シーンに `Composition` を持たせる（`genparallax/scene.py`）。AEのカメラ設定ダイアログと同じ値を保持する。

| フィールド | 意味 | 初期値 |
|---|---|---|
| `width`, `height` | コンポジションサイズ (px) | 画像と同じサイズ |
| `film_size_mm` | フィルムサイズ | 36 |
| `focal_length_mm` | 焦点距離 | 50（AEの初期プリセット） |
| `measure` | フィルムサイズ測定（水平 / 垂直 / 対角） | 水平 |
| `image_scale` | 画像のスケール（コンポ px ÷ 画像 px） | 1.0（100%） |

ズーム・画角・コンポジションサイズ(mm) は保存せず、上の値から計算する。
ズームや画角を編集したときは、AEと同じく焦点距離を書き換える。

### 内部の単位との関係

内部の長さは、これまでどおり**画像のピクセル**を単位にする。コンポジションとは次の式でつなぐ。

- 基準カメラの焦点距離（画像 px）：`f = ズーム ÷ image_scale`
- AEのz座標（コンポ px）：`z_AE = (Z − f) × image_scale`
- カメラからの距離（コンポ px）：`Z × image_scale`

ここで `Z` は内部のカメラ深度（画像 px）。`Z = f` の面が AE の z = 0 に当たる。

この方式を選んだ理由：
- 深度推定・メッシュ生成・レイヤー順の処理は画像の画素に対して動くので、変更が要らない。
- 「基準カメラから見るとPSDを再現する」という性質が、コンポサイズやスケールを変えても保たれる。

### 画像の配置

- 画像は z = 0 の平面に、コンポの中央に置く。
- スケールは任意の%のほか、「フィット（全体が収まる）」「フィル（コンポを埋める）」「100%」を選べるようにする。
  - 例：1494×840 の画像を 1920×1080 のコンポにフィルすると 128.5%。
- 位置のオフセット（中央以外への配置）は、今回は対象外とする。

### 設定を変えたときの奥行きの扱い

- **レンズ（焦点距離・画角・ズーム・フィルムサイズ・測定）を変えたとき：** 全単位の奥行きを `f` の比で拡大・縮小する。カメラからの距離の比率が保たれ、基準ビューの見え方は変わらない。AEのz値はズームに比例して変わる。
- **画像スケールやコンポサイズを変えたとき：** 同じく `f` の比で拡大・縮小する。この場合、AEのz値（コンポ px）は変わらない。

AEでは本来、カメラを変えてもレイヤーのz値は動かない。それでも比率を保つ方式にしたのは、z値を固定すると深度マップから割り当てた前後関係の比率が崩れ、基準ビューが元の絵と一致しなくなるため。

## 4. プレビュー

「基準カメラ」「元画像」「差分」「深度差分」「パララックス」の各表示は、**コンポジションの枠**を基準に描く。

- ビューにコンポの枠を収め、その中に画像をスケールどおりに置く。
- コンポの外にはみ出した部分は切り取る（AEのコンポビューと同じ見え方）。
- 画像がコンポより小さいときは、余白が見える。

「自由カメラ」「深度」「ワイヤーフレーム」は、これまでどおりビュー全体を使う。

## 5. 書き出し

### GLB

- 頂点座標は**コンポ px 基準**で書き出す。大きさはAEのモデル設定に合わせる（下記）。

#### AEでのモデル読み込み（AE 27.0 で実測、2026-11-11）

| 項目 | 結果 |
|---|---|
| 大きさ | モデル単位「メートル」・オブジェクトスケール100%で、**1 m ＝ 512 コンポ px**。コンポサイズやモデルの大きさに依らない |
| 原点 | glTF の原点がレイヤーの位置（初期値はコンポ中央、z = 0）に来る。バウンディングボックスでの中央寄せはしない |
| 向き | 上方向軸「Y軸」・Z軸反転なしで、glTF の +Y が上（AEの −Y）、−Z が奥（AEの +Z）。左右反転なし |

- 測り方：大きさの分かる四角形のGLB（1×1 m、4×1 m、原点から外した1×1 m、10×2 m、0.1×0.1 m）を読み込み、`sourceRectAtTime` とレンダー結果で確かめた。
- 書き出しの設定は「書き出しのモデル単位 (AE)」（初期値メートル）。1 px ＝ 1 ÷ (512 × 単位のメートル換算) glTF単位で書き出す。AE側で同じモデル単位を選び、スケール100%のままにすれば、コンポの1 pxがAEの1 pxになる。
- 以前の初期値（0.01単位 / px）は、AEでは5.12倍の大きさになっていた。旧プロジェクトを開くと、この値は捨ててメートルにする。
- メートル以外の単位は通常の換算（cm ＝ 0.01 m など）を仮定している。実測したのはメートルだけ。
- 同梱するカメラは、コンポジションカメラ（垂直画角とアスペクト比はコンポのもの）にする。
- 原点は、初期設定で z = 0 の平面（AEと同じ）。

### AE用JSON

すべてコンポ px で出力する。

- コンポジション：幅、高さ
- 画像：元サイズ、スケール(%)、コンポ内での位置とサイズ
- カメラ：ズーム（px と mm）、焦点距離、フィルムサイズ、測定、画角、位置 `(幅/2, 高さ/2, −ズーム)`、目標点
- 各単位：`ae_z`（AEのz座標）、カメラからの距離、凹凸の強さ

## 6. プロパティの構成（基本 / 応用）

基本は常に表示し、応用は折りたたんでおく（初期状態は閉じる）。

### 再構成単位

| 区分 | 項目 | 説明 |
|---|---|---|
| 基本 | 名前、再構成モード | 現状どおり |
| 基本 | **Z位置 (px)** | AEのz座標。0 がコンポ平面、正が奥。内部の基準奥行きと相互変換する |
| 基本 | **カメラからの距離 (px)** | `Z位置 + ズーム`。Z位置と連動する |
| 基本 | 凹凸の強さ (px) | コンポ px で表示 |
| 基本 | 下のレイヤーに沿わせる（オーバーレイ） | 現状どおり |
| 応用 | 奥行きオフセット、深度の平滑化 | |
| 応用 | 輪郭の内側オフセット、重なり境界の余白 | |
| 応用 | メッシュ密度、適応、メッシュ詳細度 | |
| 応用 | 個別の深度マップ | |

- オーバーレイの単位は、Z位置・距離・凹凸の強さを下のレイヤーから自動で決めるので、編集不可にする（現状どおり）。
- 複数選択時は、現状どおり相対的に動かす（距離の比を保つ）。

### コンポジションとカメラ

| 区分 | 項目 | 説明 |
|---|---|---|
| 基本 | コンポジションサイズ（幅・高さ） | px |
| 基本 | 画像のスケール (%) | 「フィット」「フィル」「100%」ボタン付き |
| 基本 | プリセット | 15 / 20 / 24 / 28 / 35 / 50 / 80 / 135 / 200 mm、カスタム |
| 基本 | 焦点距離 (mm) | |
| 応用 | 画角 (°)、ズーム | 編集すると焦点距離が変わる |
| 応用 | フィルムサイズ (mm)、フィルムサイズ測定 | |
| 応用 | 単位（px / mm） | ズームとコンポジションサイズの表示に使う。レイヤーのZ位置は常に px（AEと同じ） |
| 応用 | コンポジションサイズ（測定辺、読み取り専用） | AEのダイアログ右側の表示に相当 |
| 応用 | シーンの奥行き範囲 | 現状どおり |
| 応用 | パララックスの振れ幅・周期、書き出しのモデル単位 (AE) | AEのモデル設定と同じ単位 |

現在の「垂直画角」欄は、焦点距離・画角の欄に置き換えて廃止する。

## 7. 対象外（今回は扱わない）

- 被写界深度（フォーカス距離、絞り、F-Stop、ブラーレベル）。プレビューにぼかしがないため。AE側で設定する。
- 1ノードカメラ。基準カメラは目標点が z = 0 の中央にある2ノードカメラとして扱う。
- ピクセル縦横比（1.0 固定）。
- 画像の位置オフセットと回転。

## 8. 実装状況

### 実装済み（テスト 62 件通過）

- `Composition` と換算式（`genparallax/scene.py`）：`zoom_px`、`angle_of_view_deg`、`fit_scale`、`Scene.apply_composition`、`to_ae_z` / `from_ae_z`。
- 初期カメラを、AEの初期値（50 mm、36 mm、水平）に変更。
- プレビューのコンポ枠表示（`genparallax/rendering/renderer.py`）。
- GLB と AE用JSON のコンポ基準化（`genparallax/export/`）。
- プロジェクトファイルへの保存・読み込み。コンポジションを持たない旧プロジェクトは、画像サイズ＝コンポサイズとして開く。
- §6 のプロパティ画面（`genparallax/app/panels.py`）。
  - 基本 / 応用の分割。応用は折りたたみ、初期状態は閉じる。
  - 基本：名前、再構成モード、Z位置（AEのz値）、カメラからの距離、凹凸の強さ、オーバーレイ。
  - 応用：奥行きオフセット、深度の平滑化、輪郭の内側オフセット、重なり境界の余白、メッシュ密度・適応・詳細度、個別の深度マップ。
  - 基本：コンポジションサイズ、画像スケール（フィット / フィル / 100%）、レンズプリセット、焦点距離。
  - 応用：画角、ズーム、フィルムサイズ、フィルムサイズ測定、表示単位（px / mm）、測定辺のサイズ、シーンの奥行き範囲、パララックスの振れ幅・周期、書き出しのモデル単位 (AE)。
  - Z位置とカメラからの距離は連動し、複数選択時は距離の比を保つ。Z位置は内部の `base_depth` に直して編集経路へ流す。
  - コンポジションの変更は `Scene.apply_composition()` を通し、その後に全単位のメッシュを更新する。
- 旧「垂直画角」欄を廃止し、焦点距離・画角の欄に置き換え。
- 追加した文字列の日本語訳。

### 未実装

- コンポジションサイズ・画像スケールを変えた状態での、プレビューと書き出しの実機確認（スケール100%・同サイズでのみ確認済み）。
- AEでのカメラの一致の確認（GLBの大きさ・原点・向きは §5 のとおり確認済み）。

### 実装時の注意

- Z位置の欄は、内部の `base_depth` に変換してから既存の編集経路（`unitParamChanged`）に流す。変換式は `base_depth = z_AE ÷ image_scale + f − depth_offset`。
- コンポジションの変更は `Scene.apply_composition()` を通し、その後に全単位のメッシュを更新する。メッシュの位相は変わらないので、作り直しは不要。
- 追加する文字列は `genparallax/app/i18n.py` に訳を入れる（訳の漏れはテストで検出される）。
