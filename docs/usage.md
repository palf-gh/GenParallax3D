# GenParallax3D 使い方ガイド

レイヤー分けしたPSDから、After Effects（以下AE）でカメラを動かせる3Dモデル（GLB）を作るまでの手順です。

## 1. 準備

### アプリを入手する

[Releases](https://github.com/palf-gh/GenParallax3D/releases) から、使っているOS用のzipをダウンロードして展開します。

- Windows：フォルダ内の `GenParallax3D.exe` を実行します。exeはフォルダから動かさないでください。初回に SmartScreen が出たら、「詳細情報」→「実行」を選びます。
- macOS：`GenParallax3D.app` を「アプリケーション」に移します。初回は Finder で右クリック →「開く」を選びます。macOS 15 以降では、「システム設定」▸「プライバシーとセキュリティ」の「このまま開く」を使います。

配布版には、AIで深度を推定する機能は入っていません。深度マップの用意については「3. 深度マップを用意する」を見てください。

### 必要なもの

- レイヤー分けしたPSDまたはPSB
- AE 24.1 以降（3Dモデルの読み込みに対応した版）
- 必要に応じて深度マップの画像（グレースケールのPNGなど）

### PSDの作り方のコツ

- 奥行きごとにレイヤー（またはグループ）を分けます。遠景、中景、手前の人物、などです。
- 1枚のレイヤーは1つの面として扱われます。前後に大きく離れたものは、別のレイヤーにしておくと後で調整しやすくなります。
- 光芒、靄、舞う花びらのような半透明のレイヤーは、自動で「オーバーレイ」として扱われ、下のレイヤーに沿って配置されます。
- クリッピングマスクのレイヤーはベースレイヤーと一緒に1つの単位になります。

## 2. PSDを開く

1. 「ファイル」▸「PSD/PSBを開く…」（またはツールバーの「PSDを開く」）でファイルを選びます。
2. 左のパネルにレイヤーが並び、中央にプレビューが出ます。この時点では、各レイヤーが下から順に一定間隔で奥に並んでいます。

PSDをPhotoshopで直して保存すると、アプリが自動で読み込み直します（「ファイル」▸「PSDが保存されたら自動で再読み込み」）。

### 単位の統合と分割

アプリはレイヤーを「再構成単位」（以下、単位）ごとに立体にします。初期状態では1レイヤーが1単位です。

- 複数のレイヤーを1枚の面として扱いたいときは、左のパネルで選んで「1つの単位に統合」を押します。
- 元に戻すときは「単位を分割」を押します。
- レイヤー名の左のチェックを外すと、その単位は書き出されません。

## 3. 深度マップを用意する

深度マップは画像の各点がカメラからどれだけ遠いかを表すグレースケール画像です。読み込むと、各レイヤーの奥行きと表面の凹凸が自動で決まります。

### 画像を読み込む

1. 「深度」▸「深度マップを読み込む…」で画像を選びます。PSDと同じ縦横比にしてください。
2. 「この深度マップは白が『近い』ですか？」と聞かれます。白が手前なら「はい」、白が奥なら「いいえ」を選びます。

深度マップは、外部のAIツール（Depth Anything など）で作ったものを使えます。

### AIで推定する（ソースから実行している場合）

PythonとAI用の追加パッケージ（`pip install -e .[ai]`）を入れて実行している場合だけ、「深度」▸「深度を推定（Depth Anything V2 Small）」が使えます。初回はモデルをダウンロードするため時間がかかります。

### 深度マップを読み込んだ後

- 各単位の奥行き（Z位置）と凹凸の強さが、深度マップから割り当てられます。
- 「レイヤー順を自動で保つ」がオンのとき（初期値）、PSDで下にあるレイヤーが上のレイヤーを突き抜けないよう、自動で奥に押し込みます。
- 手で調整した後に深度マップの値へ戻したいときは、「深度」▸「深度マップから奥行きを割り当て直す」を使います。

## 4. プレビューで確認する

「表示」メニュー、または数字キー1〜8で表示を切り替えます。

| 表示 | 用途 |
|---|---|
| 元画像 | PSDの合成結果 |
| 基準カメラ | 3Dモデルを基準カメラから見た絵。元画像と同じに見えれば正しい状態です |
| 自由カメラ | 好きな角度から立体を確認します |
| 深度 | 奥行きを濃淡で表示します |
| 差分 | 基準カメラの絵と元画像の違い。黒に近いほど一致しています |
| 深度差分 | 深度マップと実際のメッシュの奥行きの違い |
| ワイヤーフレーム | メッシュの三角形の分割を表示します |
| パララックス | カメラを左右に揺らして、立体感を確認します |

自由カメラの操作は「ヘルプ」▸「ビューポートの操作方法」にまとめています。F キーでカメラを元に戻せます。

## 5. 調整する

右のパネルは「レイヤー」と「シーン」の2つのタブに分かれています。各タブとも、枠の中によく使う項目、折りたたみの中に細かい調整があります。最初は枠の中だけで十分です。

### 「レイヤー」タブ（左のパネルで選んだ単位）

| 項目 | 内容 |
|---|---|
| 再構成モード | 平面、深度サーフェス（深度マップどおりの凹凸）、なめらかなサーフェス、手動深度（単位ごとの深度マップ）、除外 |
| Z位置 (px) | AEのZ座標と同じ値です。0 がコンポジションの面、正の値が奥です |
| 凹凸の強さ (px) | 表面の凹凸の大きさです。0 で平らになります |
| メッシュの簡略化 | オフ／標準／強。平らな部分の三角形を大きくして頂点を減らします。輪郭と基準カメラからの見た目は変わりません |
| 下のレイヤーに沿わせる（オーバーレイ） | 半透明のレイヤーを、下のレイヤーの表面に沿わせます |

複数の単位を選んで Z位置を変えると、カメラからの距離の比を保ったまま一緒に動きます。

折りたたみの「深度設定」には、カメラからの距離、奥行きオフセット、深度の平滑化（細い格子状のレイヤーで凹凸が暴れるときに大きくします）などがあります。「メッシュ」には、メッシュ密度と詳細度があります。

### 「シーン」タブ（全体の設定）

| 項目 | 内容 |
|---|---|
| コンポジションサイズ (px) | AEで作るコンポジションと同じサイズにします |
| 画像のスケール (%) | コンポジションに対する画像の大きさです。「フィット」は全体が収まる大きさ、「フィル」はコンポジションを埋める大きさです |
| レンズのプリセット／焦点距離 (mm) | AEのカメラ設定と同じ値にします（フィルムサイズ 36 mm が前提です） |

折りたたみの「カメラ設定」では画角、ズーム、フィルムサイズなどをAEのカメラ設定ダイアログと同じ項目で指定できます。「奥行きの範囲とプレビュー」では、深度マップの最も奥の値をどこまで遠くに置くか（シーンの奥行き範囲）を変えられます。

## 6. 書き出す

「ファイル」メニューから書き出します。

- GLBを書き出し（1ファイルにまとめる）…：全単位を1つのGLBにします。手軽に使いたいとき向けです。
- GLBを書き出し（単位ごとに分ける）…：単位ごとに別のGLBを作り、フォルダにまとめます。AEでレイヤーごとに調整したいとき向けです。

GLBと一緒に `〜_ae.json` が書き出されます。ここには、コンポジション、カメラ、各単位のZ位置など、AEで使う数値が入っています。

作業を後で続けるときは、「ファイル」▸「プロジェクトを保存」で `.gp3d` ファイルを保存します。

## 7. After Effectsで使う

1. コンポジションを、アプリの「コンポジションサイズ」と同じサイズで作ります。
2. GLBを読み込み、タイムラインにドラッグします。
3. 「モデル設定」ダイアログが出たら、**初期値のまま（オブジェクトスケール 100%、モデル単位「メートル」、上方向軸「Y軸」）OK** を押します。
   - 単位ごとに分けて書き出した場合は、各GLBを同じように追加します。どれもコンポジションの中央に置かれ、位置が揃います。
   - アプリの「シーン」タブ ▸「書き出し」でモデル単位を変えた場合は、AEでも同じ単位を選びます。
4. カメラを追加します（「レイヤー」▸「新規」▸「カメラ」）。2ノードカメラにし、アプリと同じ焦点距離（フィルムサイズ 36 mm）にします。位置は初期値のままで、アプリの基準カメラと一致します。
5. カメラを少し動かすと、パララックスが付きます。

うまく合わないときは、次を確認してください。

- モデル設定のオブジェクトスケールが 100%、モデル単位がアプリと同じか
- モデルのレイヤーの位置がコンポジションの中央（Z = 0）のままか
- カメラの焦点距離とフィルムサイズがアプリと同じか

## 8. 困ったとき

- 基準カメラの絵が元画像とずれるときは、「差分」表示で、ずれている単位を探します。凹凸の強さを下げるか、「深度設定」の深度の平滑化を大きくします。
- 下のレイヤーが上のレイヤーから突き出るときは、「深度」▸「レイヤー順を整える」を実行します。
- 半透明のレイヤーの縁が浮くときは、その単位で「下のレイヤーに沿わせる（オーバーレイ）」をオンにします。
- 動作が重いときは、大きな単位の「メッシュの簡略化」を「強」にします。
- 配布版の動作を確認するには、`GenParallax3D --self-test report.txt` を実行します。同梱ライブラリとOpenGLの確認結果がファイルに書き出されます。
